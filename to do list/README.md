# Todo List Application

A fully functional todo list application with CRUD operations, filtering, and local storage persistence.

## Features

- Add, edit, delete tasks
- Mark tasks as complete/incomplete
- Filter tasks (All, Active, Completed)
- Clear completed tasks
- Task counter
- Responsive design
- Local storage persistence
- (Optional) Drag-and-drop reordering

## Technologies Used

- HTML5
- CSS3
- JavaScript
- (Optional) SortableJS for drag-and-drop
